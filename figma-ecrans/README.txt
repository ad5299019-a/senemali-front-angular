MAQUETTES SENEMALI A IMPORTER DANS FIGMA
========================================

Ce dossier contient un fichier SVG par écran (format 1440 x 1000).
Les SVG sont des maquettes vectorielles : les formes, textes et éléments UI
peuvent être sélectionnés et adaptés après import dans Figma. Ce ne sont pas
des captures d'écran aplaties.

IMPORT DANS FIGMA WEB OU DESKTOP
--------------------------------
1. Ouvrez votre fichier Figma.
2. Glissez un ou plusieurs fichiers .svg de ce dossier sur la page Figma,
   ou utilisez Fichier > Importer.
3. Placez chaque écran sur le canvas.
4. Pour modifier les éléments séparément, sélectionnez le SVG puis faites
   clic droit > Ungroup (ou Ctrl+Shift+G). Répétez si nécessaire.
5. Créez ensuite les interactions de prototype entre vos frames Figma.

Les écrans sont des références visuelles en vecteurs. Les images et vidéos
de données sont représentées par des illustrations ou des zones média.
